
# CODSOFT Cyber Security Internship - Task 2

## Project Name
Phishing Awareness Program

## Objective
To educate users about phishing attacks and help them
identify suspicious emails, fake websites, and online scams.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Phishing awareness information
- Common phishing types
- Warning signs of suspicious messages
- Online safety tips
- Interactive quiz with score

## How to Run
1. Open the project folder in VS Code.
2. Open index.html in a browser.
3. Read the educational content.
4. Complete the quiz and check your score.

CODSOFT Cyber Security Internship

## Disclaimer
This project is an educational awareness tool.
The phishing message is fictional and is not intended
to collect personal or login information.
